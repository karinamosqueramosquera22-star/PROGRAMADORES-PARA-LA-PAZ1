El login es el proceso mediante el cual un usuario se identifica para ingresar a una aplicación. Esto permite que solo las personas autorizadas puedan acceder a determinadas funciones. Algunas rutas deben estar protegidas porque contienen información privada o permiten realizar cambios importantes en el sistema. De esta forma se evita el acceso de personas no autorizadas. Además, no se deben exponer públicamente contraseñas, documentos de identidad, teléfonos, direcciones, claves de acceso, tokens ni otros datos sensibles de la comunidad.
